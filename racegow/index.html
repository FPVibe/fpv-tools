The script

Download racegow_format.py

Needs ffmpeg and a bold DejaVu/Liberation font (or set RACEGOW_FONT to a .ttf path).

chmod +x racegow_format.py
mkdir -p ~/.local/bin
ln -sf "$(pwd)/racegow_format.py" ~/.local/bin/racegow-format
chmod +x racegow_format.py
mkdir -p ~/.local/bin
ln -sf "$(pwd)/racegow_format.py" ~/.local/bin/racegow-format
# brew install ffmpeg, if needed
Save racegow_format.py next to your clip, then in that folder:

python racegow_format.py "clip.mov" --start 13.7 --laps 40.07 63.27 --end 91.07

(needs Python and ffmpeg on PATH — winget install ffmpeg)
